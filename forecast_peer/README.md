# 개별 관측 이력 보존 예측 실험

사용자 선택: **선행 탐지율 우선, 오경보 약4회/드론·h 허용**.

두 단계에서 총12개 신규 모델을 학습했다.1단계의 그래프 직접 학습·20초 관계 이력에 이어,2단계에서는 개별 상대의 RF 관측을 집계 전에 보존했다. 총119항목·1초 간격20표본이며 기존V13 예측을 고정한 채 보정층을 학습한다.

각 실험에서 학습·모델 선택·문턱 보정을 분리했다. 확인 비행은 두 실험이 공유하는42회이며 알려진14지도·세 간섭 조건이다.2단계 계획은1단계 확인 성능이 생성되기 전에 고정했다.2단계 모델·문턱을 고정할 때까지 확인 성능을 열지 않았다.2단계 고정 후 새로 생성한42회나 총84회 비행으로 주장하지 않는다.

최종 수치와 검증 근거는 `RESULTS_20261103.md`, `artifacts/final_results.json`, `audit.json`, `runtime_checks.json`이다. 루트의 `08_개별관측_학습현황.bat`는 상태와 결과를 읽기만 한다.

현재 탐지 우선 프로필 `forecast_current`는 보존한다. 이번 사전 선정안은 오경보가 줄었지만 탐지율이 낮아 기존 설정으로 자동 교체하지 않는다. 실제 장비 검증과PPO 자동 교체는 없다.

연구용 실행API:

```python
from forecast_peer.runtime import load_service
stream = load_service(city, n_drones, n_search, nominal)
```

같은 실제 수신128바이트 비컨과 로컬 관측·마스크·현재 발행 의도·측정 에너지를 매0.5초 전달한다.20초 관측 후1초 주기로 예측한다. RF 결측은 위험도None이다. 신뢰 경보는 비활성이다.
