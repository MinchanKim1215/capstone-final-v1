# Final V1 연구 검증 결과

검증 완료 2026-11-05T12:02:17+09:00 · 대표 제어 **V21 선제 제어**

## 1. 지도별 원인과 단절 전 패턴

345개 지도에서 기존 제어 비행의 반초 단위 무선 판정을 재현했다. 새 단절 2,572건과 시작부터 연결이 끊긴 14구간을 분리했다.

| 유형 | 새 단절 | 건물 손실만 제거해 첫 1초 회복 |
|---|---:|---:|
| 급락형 | 1,676 | 1,670 |
| 혼합형 | 509 | 509 |
| 이력 부족 | 4 | 4 |
| 기타 | 282 | 139 |
| 점진형 | 101 | 71 |

급락은 마지막 0.5초에 통신 여유가 6dB 이상 감소한 경우다. 점진은 직전 프레임 이전의 두 구간 중앙값 차가 3dB 이상인 경우다. 둘 다 충족하면 혼합이다. 문턱을 4/2dB 및 8/4dB로 바꾼 집계도 저장했다. 통신 여유는 대칭 SINR 기준의 근사 dB값이며, 실제 연결 판정은 별도로 데이터·ACK 성공확률을 재현해 원본과 일치시켰다.

## 2. 연속 예측 입력과 PPO 학습

훈련 지도 245개, 예측 입력 154,312행. 다음 단절 시점을 0.5~3초, 3~5초, 5~7초, 해당 구간 내 없음으로 나눴다. 계획된 보정 유지·기본 대형 복귀의 214개 통신 특징에서 만든 24차원 표현과 네 시간 점수, 관측 여부를 PPO에 전달했다. 기존 정책을 기준으로 추가 행동 점수만 학습했다. 같은 구조에서 새 입력만 제외한 정책도 별도로 학습했다.

| 방식 | PPO 갱신 | 신규 학습 비행 | 행동 시점 | PPO→예측기 최대 기울기 |

## 4. 명령 전달, 복구와 재생 화면

첫 중계기가 계산을 맡는 구성을 가정했다. 마지막 무선 프레임에서 얻은 홉 성공 모델로 명령 전달을 표본 추출했다. 수신 실패 시 기본 대형 또는 직전 한 주기 명령과 로컬 관측을 사용하는 규칙을 비교했다. 수신 실패의 방향과 시점을 통제하는 강제 손실을 함께 사용했다.

| 수신 실패 대응 | 원격 명령 수신 | 새 단절 | 10초 내 안정 복구 | 복구 중앙값 | 안전 위반 |
|---|---:|---:|---:|---:|---:|
| 미수신 시 기본 대형 | 32,941/34,340 | 68 | 58/68 | 3.5초 | 0 |
| 미수신 시 자율 보정 | 32,894/34,264 | 71 | 53/71 | 5.5초 | 0 |
| 자율 보정 · 복구 분기 제외 | 32,913/34,264 | 65 | 51/65 | 5.0초 | 0 |

로컬 자율 보정과 기본 대형 대응의 시간당 새 단절 차이 +0.44회/h (공간 그룹 95% [-1.51, +2.40]). 로컬 대응 비행에서 실행 직전 실제 수색망이 끊긴 복구 명령은 3회였다.

명령 손실 설정에서 채택한 대응은 **미수신 시 기본 대형**다. 재생 화면에서는 같은 지도·난수의 경로, 통신 링크, 개입 근거, 명령 미수신과 대응을 나란히 볼 수 있다.

공동 항법 정보와 명령 채널 모델은 시뮬레이션 가정이다. 실제 지연, 채널 점유, 장비 검증은 별도다. 워크스페이스에서 확인 가능한 코드를 대상으로 통합했다. 별도로 전달되지 않은 팀원 변경분은 검증 범위 밖이다.
