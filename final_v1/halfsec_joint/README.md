# Final V1 · 0.5초 Transformer–PPO 공동학습

검증된 `v21_transformer`의 링크 표현층, 단절 시점 출력층과 전체망 위험 모델을 초기값으로 사용한다. 기존 V21 LightGBM은 선행 점수 결합과 임박 위험 검사에 사용한다. 새 PPO는 0.5초 비행 환경의 안전 후보와 유지 행동을 평가하도록 구성했다.

## 관측과 제어

- 0.5초마다 최근 40개 관측을 사용한다. 무선 입력은 도착한 비컨과 지연된 이웃 수신 보고에서 읽는다. 수색 계획과 현재 예약 간선은 공유 항법 상태에서 얻는다. 빠른 환경에서 제공되지 않는 패킷 관측은 입력 마스크로 구분한다.
- 수신 처리 0.1초, 경로 계산 0.2초와 명령 전달 0.1초를 반영한다. 비컨은 1초, 전파 판정은 0.5초, 안전 간선의 운동 계산은 0.1초 주기다.
- 같은 비행에서 나온 링크·전체망의 단절 시작 시점을 지도학습 정답으로 사용한다. PPO는 안전 후보 중 실제로 선택한 행동과 보상을 기록하고, 같은 관측으로 행동 확률을 재현한다. PPO 손실과 예측 손실을 함께 역전파한다.
- 대안 이동이 예정 수색 진행을 늦추거나 새로 수색 통로를 막는지 검사한다. LightGBM 임박 위험이 허용 범위를 넘는 후보도 제외한다.

## 실행과 결과

```powershell
& .\drone_forecast_joint_training\.venv\Scripts\python.exe -B -u -m final_v1.halfsec_joint.run --workers 6
```

첫 실행은 사전 비행 두 편과 CUDA 갱신을 확인한 뒤 학습 지도 447곳의 480개 비행을 수행한다. 6개 비행마다 GPU에서 갱신하고 지문을 기록한다. 같은 명령으로 `artifacts/latest.json`에 기록된 저장본부터 재개한다. 실제 진행은 `artifacts/status.json`, 갱신별 근거는 `artifacts/updates/`에 있다.

별도 개발 지도에서 후보와 경보 평가 문턱을 고정한 뒤 45개 확인 조건을 평가한다. 확인 지도는 이 학습과 보정에서 분리하며 과거 확인에 쓰인 지도에 새 비행 조건을 적용한다. 같은 빠른 환경에서 초기 모델의 3초와 0.5초를 비교하고, 0.5초 초기 모델과 학습 후보를 비교한다. 마지막으로 기존 Final V1 전체와 비교한다. 이전 경로 정체 조건은 별도 재현한다. 최종 지표와 채택 판정은 `artifacts/results.json`에 기록한다.
