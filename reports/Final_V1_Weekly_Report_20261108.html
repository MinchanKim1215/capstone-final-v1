04 · 주간 작업

원인 조사에서 선제 제어 검증까지

  1. 11.02–11.03

    예측 입력과 모델 대조

    수신한 비컨·패킷 기록, 시간 그래프, 물리 경로 예측을 비교했다. 놓친 사건에서 경로 부재와 패킷 적체가 함께 나타나는지 확인했다.

  2. 11.04

    전체 지도에서 단절 원인 조사

    345개 지도 비행과 동일 경로 1,035조건의 간섭 재생을 분석했다. 건물 차폐·간섭·섀도잉을 각각 제거해 시작 시점의 복구 여부를 대조했다.

  3. 11.05

    차폐 기반 선행경보와 V21 선제 재배치

    예정 경로의 차폐와 우회 연결을 계산해 위험 시점을 앞당겼다. 별도 42조건의 전체 임무에서 기존 V7 PPO 대비 V21의 새 단절이 246 → 166건으로 줄었다. 단절 전 이력은 30초로 확장했다.

  4. 11.07

    지도 300개 추가와 0.5초 판단 실험

    등록 지도는 총 645개가 됐다. 별도 실험 환경의 동일 36조건에서 물리 제어 판단을 3초에서 0.5초로 줄였을 때 새 단절이 341 → 242건으로 감소했다. 기존 Final V1 대비 임무 시간 조건을 충족하지 못해 실험 버전으로 보관했다.

  5. 11.08

    Final V1 기본 Transformer 업데이트

    링크 단절 시간 출력층을 갱신하고 전체망 위험 점수를 결합했다. 36조건의 전체 임무 검증을 통과해 기본 제어에 편입했다. 후속 공동학습은 학습 비행 448회와 GPU 갱신 56회를 마치고 17:17에 별도 최종 평가를 완료했다.

장기 공동학습 후보 · 채택 기준 미달. 별도 45조건에서 현재 Final V1 대비 선행탐지율은 56.03% → 55.17%(130 → 128/232건), 새 단절은 193 → 194건, 누적 단절 시간은 1,214.5초 → 1,255.0초였다. 56회 갱신 저장본으로 지도 캐시 오류 이후 최종 평가를 재개해 135개 비행 기록을 검증했다.

05 · 근거

지표 정의와 원본 자료

지표와 단절 분류 기준 보기
선행탐지율
3초 이상 7초 미만 앞서 경보를 맞힌 사건 수를 전체 새 단절 수로 나눈 값.
정밀도와 AP
정밀도는 전체 경보에서 제때 맞힌 경보의 비율. AP는 문턱을 바꿔가며 본 정밀도와 재현율의 관계를 요약한 위험 순위 지표.
오경보·늦은 경보
선행 구간 내 단절과 매칭되지 않은 경보 수를 편대 비행 시간으로 나눈 값.
통신 여유
직접·중계 경로를 고려한 수색망 전파 여유의 근사값(dB). 0dB는 근사 경계다. 지속 단절은 별도의 데이터·ACK 링크 판정으로 결정했다.
유형 문턱
마지막 0.5초 감소가 6dB 이상이면 급락 조건을 충족한다. −6~−4.5초와 −2~−0.5초의 중앙값 감소가 3dB 이상이면 점진 조건을 충족한다. 두 조건을 모두 충족하면 혼합형이다.
%와 %p
단절 감소율은 기존 값 대비 비율. 탐지율처럼 이미 퍼센트인 값의 차이는 퍼센트포인트. 증감은 반올림 전 수치로 계산했다.
