# 탐지율 우선 연구용 실행 설정

사용자 선택 **“탐지율을 우선하고 약4회/h 오경보 허용”**을 반영한 현재 연구용 프로필이다.

선정 모델은 `v13_memory_event`, 경보 문턱은0.33이다. 동일한42비행·174개 서비스 장애 사건에서 다음 결과를 기록한 기존 검증 옵션이다.

| 지표 | 같은 오경보 예산에서 보정한 기존 모델 | 선택한 모델 |
|---|---:|---:|
| 선행 탐지율 | 24.71% | 31.61% |
| 탐지 사건 | 43/174 | 55/174 |
| 경보 정밀도 | 33.33% | 38.78% |
| 실제 오경보·늦은 경보/h | 4.05 | 4.24 |

이 옵션은 보정 자료의FA5 후보 중 실제 확인 비행에서 약4.24회/h를 기록한 운영점이다. 오경보4회/h를 항상 보장하는 하드 상한이 아니다. 실사용 신뢰 목표에는 미달한다.

## 실행 경로

```python
from forecast_current.runtime import load_service

stream = load_service(city, n_drones, n_search, nominal)
```

이 실행 경로는 별도의 예산 인자 없이 사용자가 선택한 옵션을 불러온다. 매0.5초의 로컬 관측·마스크·현재 발행 의도·측정 에너지, 실제 받은 비컨과 자신의 비컨을 기존API와 같은 순서로 전달한다.20초 관측 후1초마다 위험도를 계산한다.

원본V13 모델·실험·보고서·기본 비교API는 보존한다. 현재 설정은 `active_profile.json`에 저장하며, 원본 소스·모델·보정 계획의 해시를 확인한다. 새로운 학습이나 재평가 수치로 표시하지 않는다. 기존PPO 제어기에 새 서비스 예측기를 자동 삽입하지 않는다.

연구용 추론이며 `trusted_alarm_enabled=False`다. 실제 장비 검증과 자동PPO 교체는 활성화하지 않는다.

루트의 `06_탐지우선_설정확인.bat`는 설정과 기존 검증 수치만 표시한다.
