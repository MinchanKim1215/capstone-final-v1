# 현재 연구용 프로필 선택 이력

2026-11-03 사용자 답변 “탐지율을 우선하고 약4회/h 오경보 허용”을 반영했다.

- `active_profile.json`: 승인한 선택, 현재 모델·문턱·기존 검증 수치·원본 해시를 기록했다.
- `runtime.load_service`: 별도 예산 인자 없이V13의 검증된FA5 보정 운영점(문턱0.33)을 불러온다.
- 기존 확인42비행에서는55/174건 탐지(31.61%), 경보 정밀도38.78%, 실제오경보4.24회/h였다. 이 단계의 새로운 학습·평가 결과가 아니다.
- 새 기본 경로를 실제 과거 관측60프레임으로 확인했다.20초 준비 후11회 예측·22개 유효 위험도를 정상 반환했다. 동일 옵션의 기존 전체3,168프레임 검증은 경보 판단 차이0건이었다.
- 이전V13 납품140개 파일과 부가 파일1개를 보존했다. 이전 실험 보고서의 선택 당시 상태는 수정하지 않았다.

이 프로필은 연구용 추론 경로다. 기존PPO의 물리 링크 예측 입력에 새 서비스 예측기를 자동 삽입하지 않았다. 실제 장비 검증·신뢰 경보·자동PPO 교체는 비활성이다.

다음 학습이나 추가 개선 요청에서는 탐지율 우선·실제오경보약4회/h 허용이라는 사용자 선호를 유지한다. 기존동결 실험을 수정하거나 이번 선택을 새로운 학습 성능 향상으로 표시하지 않는다.
