## 1. 구현한 동작

`공개 지도 정보·출동 제약 → 출발 전 대형 선택 → 매 1초 예측 갱신 → 매 3초 중계 이동 → 실제 결과로 공동학습`

| 선택 후보 | 전체 / 수색 / 중계 | 배치·간격 |
|---|---:|---|
| 기존 8대 구성 | 8 / 3 / 5대 | V형·40m |
| 6대 횡렬 | 6 / 4 / 2대 | 횡렬·20m |
| 10대 횡렬 | 10 / 6 / 4대 | 횡렬·20m |
| 6대 V형 | 6 / 4 / 2대 | V형·40m |

- **대형 선택:** 건물 높이·개수·건물 점유 격자·비행 제한 격자 등 공개 입력 140개 사용. 가용 기체 수와 최소 수색 기체 수를 만족하는 후보만 선택. 비행 도중 기체 수 변경 없음.
- **예측:** 1초마다 향후 8초 이내의 다음 지속 단절 시작 시점을 예측. 0.5초 간격 16구간과 시작 없음 1개로 구성. ‘1초 예측기’는 갱신 주기를 뜻하며 예측 범위가 1초뿐이라는 뜻이 아님.
- **공동학습:** Transformer·시간 출력층에는 예측 정답 오차와 PPO 행동 보상 전달. 중계 이동 정책과 임무 전 대형 선택기도 갱신. 현재 상태를 사용하는 중앙 가치망은 실행 정책 입력과 분리.
- **초기화:** 예측기는 기존 1초 실험 best 5,500에서 초기화. 가변 대수 이동 정책과 대형 선택기는 새 학습 대상. 기존 176번 정책을 그대로 확장한 모델이 아님.
- **관측 부족 처리:** 오래되거나 부족한 관측을 위험도 0으로 취급하지 않음. 지원되지 않는 링크를 별도 표시.

## 3. 새 학습 및 평가 계획

- 학습 지역 166개 사용. 기본 상한 256회 갱신 × 8비행 = 2,048비행. 조기 종료 조건 포함.
- 초기 16회 갱신은 네 대형을 균등 수집. 이후 선택기의 실제 확률로 대형 결정. 강제 균등 선택 자료로 선택기 PPO를 갱신하지 않음.
- 기존 개발 지역 24개를 모델 선택 8개 / 경보 문턱 보정 8개 / 확인 8개로 분리. 인접 공간 그룹 유지. 과거 사용된 개발 지역이므로 독립 최종 시험으로 주장하지 않음.
- 같은 지도·방향·난수·간섭에서 고정 네 대형과 자동 선택 비교. 원본 176번 모델은 허용되는 8대 조건에서 동결 비교.
- 예측 성능은 동일 관측 재생으로 별도 비교. AP·AUROC·Brier·정밀도·재현율·선행시간·시간당 오경보를 함께 기록.
- 경보 개발 목표: 정밀도 90%, 3초 선행 사건 재현율 80%, 드론·시간당 오경보 또는 늦은 경보 1회 이하, 경보 20개 이상. **교수님 지정값이나 달성값이 아님.** 모두 만족하지 못하면 경보 비활성화.
- 모델·경보를 동결한 이후에만 최종 평가 지도 32개 사용.

현재 새 모델의 예측 정확도·연결률 향상률은 미측정이다. 네 대형이 모두 최적이라는 근거도 없다. 기존 6대 V형은 과거 재검증에서 PDR 기준에 미달한 후보이므로, 자동 선택 이득은 새 학습 후 확인해야 한다.

## 4. 지표 용어와 정정

| 용어 | 의미 |
|---|---|
| 공동학습 | 예측기와 행동 정책을 연결하고 예측 정답·행동 보상으로 함께 갱신하는 구성 |
| PPO | 행동 결과의 보상을 이용해 정책을 갱신하는 강화학습 방법 |
| CTR | 모든 수색 드론이 서로 도달 가능한 시간 비율 |
| PDR | 생성된 패킷 중 전달된 패킷의 비율 |
| AP | 여러 경보 문턱에서 정밀도·재현율 관계를 요약한 예측 순위 지표 |
| AUROC | 양성·음성 표본의 점수 분리 정도. 정답률 90%와 동일하지 않음 |
| Brier | 예측 확률과 실제 발생 여부의 제곱 오차. 낮을수록 좋음 |
| 사건 재현율 | 실제 단절 사건 중 요구 선행시간을 만족한 경보가 있었던 비율 |

**기존 설명 정정:** 이 시뮬레이터에는 별도 지상 기지국 노드가 없다. CTR을 ‘기지국 연결률’이라고 표현한 이전 설명은 부정확하다. ‘수색 드론 간 전체 연결 시간 비율’로 해석해야 한다.

0개 경보의 정밀도와 새 정의로 측정하지 않은 기존 모델의 예측 지표는 미정·미측정으로 기록한다. 이를 0% 성능으로 표시하여 향상률을 만들지 않는다. 경보 문턱 보정과 확률 자체의 보정도 구분한다.
