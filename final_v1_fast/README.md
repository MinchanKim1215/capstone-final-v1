# Final V1 · 빠른 제어 주기 공학 실험

기존 Final V1을 보존한 채 명령 판단·관측·계산·전달·이동의 시계를 분리한다. 기존 V21 비행 42개에서 고정한 113개 출발 조건을 24초씩 분기한다. 위험 구간 71개와 연결 유지 구간 42개이며 지도는 14개다.

## 비교 구성

| 구성 | 재배치 판단 | 비컨 | 긴급 감시 |
|---|---:|---:|---:|
| p3_b1 | 3초 | 1Hz | 없음 |
| p1_b1 | 1초 | 1Hz | 없음 |
| p05_b1 | 0.5초 | 1Hz | 없음 |
| p05_b10 | 0.5초 | 모든 기체 10Hz | 없음 |
| p05_b10_e02 | 0.5초 | 모든 기체 10Hz | 0.2초 |
| p05_b10_e01 | 0.5초 | 모든 기체 10Hz | 0.1초 |
| p05_bhybrid | 0.5초 | 중요 링크 두 끝 10Hz, 나머지 1Hz | 없음 |
| p05_bhybrid_e01 | 0.5초 | 중요 링크 두 끝 10Hz, 나머지 1Hz | 0.1초 |

중요 링크 선택은 수신 자료와 발행 경로의 예측만 사용한다. 보고 주기 변경도 명령 지연·손실을 거치므로, 변경 명령을 받지 못한 기체는 이전 주기를 유지한다. 개발 단계의 통신 비용을 근거로 추가한 두 방식은 확인 분기 결과를 열기 전에 `artifacts/protocol_v2.json`에 등록했다. 최초 여섯 방식 등록은 `artifacts/protocol.json`에 남아 있다.

## 시간·운동·통신 조건

- 전파·패킷 경로 갱신·운동 적분은 0.1초. 그림자 과정은 기존 0.5초 끝점에 조건부인 새 OU 과정이다.
- 센서 처리 0.1초, 계획 계산 0.2초, 명령 전달 기본 0.1초. 지연 추가 시험에서는 명령 전달만 0.3초로 한다.
- 계산이 끝나기 전에 그 결과로 명령이나 보고 주기를 바꾸지 않는다. 한 계획기가 바쁜 동안의 추가 요청은 건너뛰고 센서 감시는 계속한다.
- 최대 속도 5m/s, 가속도 2.5m/s², 최소 분리 5m. 지도에서 검증한 간선만 이동하며 시간 예약으로 충돌을 피한다.
- 이번 운동 모형은 각 간선의 끝에서 정지하고 다음 간선을 선택한다. 목표는 이동 중에도 갱신할 수 있지만, 기체가 간선 중간에서 즉시 선회하거나 급정지하는 기능은 포함하지 않는다.
- 비컨은 기체당 5ms, 명령은 100ms마다 순차 전달 최대 세 슬롯이다. 동일한 데이터 채널의 슬롯을 실제로 줄인다. 8대의 전 기체 10Hz 비컨은 명령과 함께 55%를 차지한다.

## 현재 Final V1과의 관계

원본 항법 생성기를 출발 시점까지 그대로 재현하고, 해당 시점에 발행한 PPO/V21 보정을 유지하는 미래 계획을 만든다. 이후 원본 파일의 실제 행동·위치·전파를 제어 입력으로 주지 않는다. 이 위에 동일한 물리 예측 보호 규칙을 서로 다른 주기로 실행한다.

모든 방식의 출발 위치는 같고 초기 속도·큐는 0으로 맞춘다. 따라서 원래 V21 전체 임무를 그대로 고주기로 돌렸다는 의미가 아니다. 학습한 PPO를 다른 시간 간격에 그대로 재사용하거나, 기존 전체 임무 개선률과 이 수치를 섞어 보고하지 않는다. 이번 결과만으로 운영 코드를 교체하지 않는다.

## 확인·재개

작업 폴더에서 다음 명령을 사용한다.

```powershell
./drone_forecast_joint_training/.venv/Scripts/python.exe -m unittest final_v1_fast.test_contracts -v
./drone_forecast_joint_training/.venv/Scripts/python.exe -m final_v1_fast.campaign
```

시나리오·구현을 고정한 뒤에는 저장된 결과의 계약과 파일 지문을 확인하며 재개한다. 구현 변경이 필요하면 기존 확인 결과를 덮어쓰지 않고 새 실험으로 분리해야 한다.

`artifacts/status.json`은 진행 상태, `artifacts/results.json`은 전체 지표, `artifacts/audit.json`은 독립 재집계와 보존 검사, `RESULTS.md`는 완료 보고서다. 새 지속 단절은 1초 이상 이어진 전체 수색망 분리로 정의한다. 초기 단절은 별도로 보고한다. 선택된 위험 구간의 실험이므로 전체 임무 오경보/h와 실기체 신뢰도를 추정하지 않는다.
