# 검증 자료 구성 수정 기록

2026-11-02, 독립 확인 예측 결과 개봉 전 기록.

초기 수집은 선택·보정·확인 지도를 번갈아 배치한 뒤 수집 순번으로 간섭 유형을 정했다. 두 순환의 길이가 3으로 같아 선택은 연속, 보정은 간헐, 확인은 무간섭으로 치우쳤다. 이는 비교 모델의 성능 결과가 아니라 수집 계획을 점검해 발견한 설계 문제이다.

원본 자료는 삭제하지 않는다. 각 개발 지도에 나머지 두 간섭 유형을 같은 시드·방향으로 추가한다. 공간 구분은 유지한다.

- 모델 선택: 15개 지역 × 세 간섭 유형 = 45비행.
- 확률 보정·경보 문턱: 15개 지역 × 세 유형 = 45비행.
- 모델·경보 동결 뒤 확인: 14개 지역 × 세 유형 = 42비행.
- 최종 평가 32개 지도는 계속 미사용.

각 지도에서 한 비행만 있는 기존 역사적 검증 기록은 초기 엔지니어링 비교에만 둔다. 최종 비교는 이번에 수집한 세 조건의 새 비행만 사용한다. 원래 검증 지도의 일부는 이전 예측기 사전학습에서 역사적 노출이 있으므로, 기존 지역·새 추가 지역의 확인 결과도 구분해 보고한다.

학습 지도·학습 표본·기존 모델은 변경하지 않는다. 추가 검증으로 모델을 선택하되 보정 또는 확인 결과를 보고 다시 선택하지 않는다.
