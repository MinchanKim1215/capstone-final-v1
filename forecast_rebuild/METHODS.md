# 예측 성능 우선 재구성: 설계와 환경 점검

2026-11-02. 기존 v5·v6·v7과 별도인 `forecast_rebuild` 연구 환경. 성능 수치는 `RESULTS_20261102.md`와 원시 평가 JSON을 기준으로 확인한다.

## 1. 해결 대상으로 정의한 문제

기존 예측기는 현재 연결된 링크의 다음 단절을 학습했다. 실제 경보 평가는 회복 후 재단절을 포함한 모든 지속 단절을 대상으로 했다. 학습 정답과 경보 목적의 차이를 먼저 줄였다. 연결 유지 보상으로 예측기가 간접 개선되기를 기대하는 방식에서, 예측 목적을 직접 학습하는 방식으로 분리했다.

- 단절 정답: 양방향 이론적 단일 홉 성공확률이 0.9 이상인 상태에서, 이 기준을 1초 이상 충족하지 못하기 시작하는 시점. 실제 장비의 패킷 전달률과 동일하지 않다.
- 예측 창: 앞으로 1·3·5·8초 이내의 단절, 3~4초 및 3~7초 뒤 단절. 경계는 반개구간. 반복 단절을 포함한다.
- 관측 갱신 0.5초, 예측 출력 1초, 과거 이력 20초, 기존 이동 제어 3초. 서로 다른 주기다.
- 현재 연결된 링크에 한정한 5초 단절은 기존과 같은 정답으로 직접 비교한다.
- LightGBM 주 비교 후보는 5초 및 3~7초 두 출력만 학습한다. 잔차 Transformer 계열은 여섯 창과 17개 다음 사건 시간 범주를 함께 학습한다. 선정 모델의 실제 제공 출력은 해당 모델 파일과 실행 API를 따른다.

## 2. 추가한 관측과 정답

| 구성 | 역할 | 미래 정보 방지·한계 |
|---|---|---|
| 통신 이력 요약 | ACK, SINR, 비콘, 역방향 관측, 대기열, 거리·속도 변화 | 해당 중계 드론이 실제 받은 과거 관측만 사용 |
| 결측·경과 시간 | 오래된 수치와 신선한 수치 구분 | 정보 없음이 위험도 0으로 바뀌지 않음 |
| 같은 관측자의 다른 이웃 | 주변 링크가 함께 나빠지는 상황 구분 | 다른 드론의 미수신 내부 관측은 사용하지 않음 |
| 공개 지도 기하 | 건물 차폐·회절·이동에 따른 손실 변화 추정 | 실제 미래 위치 대신 현재 속도·수신 명령 이용 |
| 공개 명목 경로 | 계획 경로 진행과 등속 이동을 대안으로 예측 | 경로는 비행 전 생성. 진행도는 받은 과거 위치로 추정. 실제 미래 PPO 명령·위치 제외 |
| 유휴 채널 에너지 | 잡음과 간섭의 현재 변화 관측 | 선택적 가상 센서. 간섭원 위치·출력·미래 작동 시각은 모델 입력에서 제외 |
| 연속 RF 보조 정답 | 향후 1~8초 최소 SINR의 분위수 학습 | 미래 RF는 지도학습 정답으로만 사용. 입력에 포함하지 않음 |

기본 정적 특징 646개. 공개 경로 대안 82개를 더하면 728개. 신경망은 별도로 40프레임의 111차원 시계열을 입력받는다. 자료·모델의 지역 이름, 분할 번호, 난수 시드 및 비공개 간섭 스케줄은 예측 입력에 없다.

가상 에너지 센서 가정은 측정 잡음 표준편차 0.75dB, 양자화 0.1dB, 결측 확률 1%다. 자기 측정의 물리 시각은 관측 끝보다 0.5초 전이다. 이웃 값은 성공적으로 수신한 비콘에 실린 이전 측정만 전달하므로 최소 1초 전 값이다. 이 수치는 장비 실측 성능이 아니다.

현재 간섭원은 지도 내 고정 지상 위치, 높이 2m, 출력 -3~3dBm이다. 지속 조건은 임무 내내 송신한다. 코드의 `intermittent`는 기준 임무 시간의 15~45% 지점에서 켜지고 65~90% 지점에서 꺼지는 **한 번의 송신 구간**이다. 반복 버스트·다중 송신기·이동 간섭을 모사한 조건은 아니다.

새 비콘 직렬화 시제품은 10대 구성의 9개 이웃 캐시, 위치·속도·현재 명령, 에너지·측정 시각을 넣고, 예약 MAC 24바이트 포함 125바이트다. 기존 추상 비콘의 128바이트 예산 이내다. 실제 무선 프로토콜·암호화 헤더·링크 품질·시계 동기화 검증은 별도다. 시뮬레이터에 설치한 실제 무선 드라이버라는 의미는 아니다.

## 3. 데이터와 실험 분리

기존 학습 공간 경계를 보존했다. 훈련 지도 245개, 학습 기록 319비행, 표본 535,200개다. 이 중 새 학습 비행 95개는 추가 지도 79개와 기존 지도 16개다. 오래된 기록은 현재 분할에서 훈련인 지역만 재사용했다. 신규 훈련 정답을 만들 때 단절 직전만 편향되게 과표집하지 않았다.

개발 검증 지도 44개는 선택 15·확률 보정 15·독립 확인 14개로 구분한다. 각 지도에서 무간섭·간헐 간섭·지속 간섭 비행을 1개씩 마련했다. 선택 45비행, 보정 45비행, 확인 42비행이다. 방향과 난수 조건은 같은 지도의 간섭 비교에 맞춰 유지했다.

초기 수집 순서와 간섭 종류가 맞물려 검증 분할별 간섭 종류가 치우친 문제를 확인했다. 확인 예측 결과를 열기 전에 누락된 88비행을 추가했다. 변경 이유와 규칙은 `DATA_COHORT_CORRECTION.md`에 기록했다. 이전 혼합 24비행 결과는 예비 진단으로만 보존했다.

기존 초기 예측기는 과거 검증 비행 8개를 이미 학습한 이력이 있다. 기존 지역 전체를 완전히 처음 보는 시험으로 표현하지 않는다. 새 지역과 기존 지역 결과를 나누어 보고한다. 기존 최종 평가 지도 32개는 이번 연구에서도 봉인한다. 이번 확인은 개발 확인이며, 봉인된 최종 시험 성적이 아니다.

## 4. 학습·선택·확률 보정

LightGBM 기본·에너지·경로 추가 3개, 잔차 Transformer 기본·에너지·경로 추가 3개, 연속 RF 보조 정답을 추가한 Transformer 1개를 학습한다. 신경망 후보는 각각 5,000개 업데이트까지 수행한다. 기존 예측기에서 출발하는 잔차 모델은 초기 출력이 기존 모델과 일치하도록 구성했다. 새로운 PPO 보상 경사는 이 예측기에 전달하지 않는다.

초기 TCN 실험의 낮은 성능도 기록으로 보존한다. 모델이 크거나 시간 모델이라는 이유로 채택하지 않는다. 본 비교에서는 7개 후보와 기존 기준 모델을 동일 비행에서 평가한다. 선택 자료만으로 최고 트리와 최고 신경망의 가중 평균 0.25·0.5·0.75를 추가 비교한다. 최종 선택 기준은 공통 5초 AP와 공통 3~7초 AP의 산술평균이다.

보정 지도에서 Platt 확률 보정과 경보 문턱을 설정한다. 두 예측 창에 별도 기울기·절편을 맞춘다. 보정은 확률과 실제 빈도의 일치를 위한 절차다. 예측 순위나 보이지 않는 전조를 새로 만들어내는 절차가 아니다.

개발 목표 예: 3초 이상 선행 사건 재현율 80% 이상, 경보 정밀도 90% 이상, 오경보·늦은 경보 1회/중계 드론·시간 이하, 경보 표본 최소 50개. 교수 지정치나 이미 달성한 값이 아니다. 목표를 동시에 맞추지 못하면 신뢰 경보 활성화를 금지하고 연구용 출력으로 남긴다. 에너지 후보는 신선한 자기·이웃 측정이 실제 있을 때만 센서 자격 경보를 허용하되, 관측 없는 단절도 재현율 분모에서 빼지 않는다.

보조 운영점은 보정 자료에서 경보 정밀도 90%와 오경보 1회/시간을 우선 만족하는 문턱 중 사건 재현율이 가장 큰 지점이다. 최소 경보 50개를 요구한다. 이 지점은 사건 재현율 80%를 요구하지 않으므로, 존재하더라도 전체 목표 달성으로 표현하거나 자동 활성화하지 않는다. 이 규칙은 확인 자료 개봉 전에 설정한다.

선택 모델·가중치·보정·문턱·평가 코드의 해시를 동결한 뒤 확인 자료에 적용한다. 확인 결과를 보고 모델이나 문턱을 다시 고르지 않는다.

## 5. 실사용을 위해 남은 환경 요소

| 요소 | 현재 반영 상태 | 다음 검증 |
|---|---|---|
| 건물 형상·높이·차폐·회절 | 공개 지도와 Bullington 기반 | 건물 높이 오차, 수목·차량·이동 차폐 측정 |
| 그림자 감쇠·시간 변화 | 1.5dB, 상관 시간 4초 | 지역·거리·LoS별 실측 분포로 보정 |
| 간섭 | 고정 지상 간섭원의 3개 작동 조건 | 실제 채널 점유율, 다중·이동 간섭원, 다른 송신 장치 |
| 위치·속도·명령 | 시뮬레이션 좌표, 수신 경과 시간 | GNSS 오차, 자세·고도 변화, 명령 지연·동기화 |
| 무선 채널 | 2.4GHz·10dBm·1MHz·1Mbps·잡음 -107dBm | 선정 모듈의 주파수·변조·속도 적응·감도·안테나·기체 차폐 |
| 패킷·제어 | 기존 TDMA·큐·재시도·라우팅 유지 | 실제 MAC 충돌, 통신·추론 지연, 재배치 후 분포 변화 |
| 단절 정답 | 이론적 양방향 홉 성공확률 문턱 | 실측 PDR·연속 패킷 유실·지연 기반 서비스 단절 정의 |

이 표의 미측정 항목에 임의의 ‘실제값’을 넣어 실사용 성능이라고 부르지 않는다. 현재 채널을 쉽게 바꿔 점수를 높이는 방식도 사용하지 않는다. 추가 센서는 입력 실험이며, 기존 기준 모델과의 물리적 단절 정답과 비행은 동일하다.

측정 스트레스는 선택 자료의 사전 규칙으로 정한 기존 지도 1개와 추가 지도 1개의 세 간섭 조건에서 실시한다. 에너지 없음, 에너지 추가 잡음 표준편차 2.5dB, 드론별 고정 위치 편차(축별 표준편차 2m)를 시험 가정으로 사용한다. 위치 편차 시 지도 기하·현재 손실 추정·경로 특징을 모두 같은 오차 좌표로 다시 계산한다. 실제 물리적 비행·정답은 고정하므로 제어계 전체의 위치 오차 시험은 아니다.

## 6. 해석 원칙과 용어

실행 정밀도 부록: 원래 실시간 계획 계산은 일부 float32 연산 때문에 동결된 배치 계획 계산과 최대 한 float32 ULP 차이가 있었다. 트리 분기 경계를 통과하면서 확률 차이 약 0.0000345가 발생했다. `runtime_stable.py`는 배치 계약과 동일하게 먼저 float64로 변환하는 추가 어댑터다. 동결 모델·평가·정답은 변경하지 않았다. 전체 한 비행 3,362프레임·10,355개 지원 링크 예측에서 특징·확률·경보 판단이 완전히 일치함을 확인했다. 부록 소스의 별도 해시를 감사 결과와 후보 목록에 기록한다.

- AP: 정밀도와 재현율을 여러 문턱에서 요약한 순위 지표. ‘경보가 맞을 확률’ 또는 ‘사건을 발견한 비율’과 다르다.
- AUROC: 양성과 음성을 구분하는 순위 지표. 0.95여도 경보의 95%가 맞는다는 뜻은 아니다.
- 경보 정밀도: 발생한 최초 경보 중 3~7초 뒤 실제 지속 단절과 맞는 비율.
- 사건 재현율: 전체 지속 단절 중 최소 3초 전에 최초 경보가 있었던 비율. 관측 부족 사건도 포함한다.
- 오경보·늦은 경보/중계 드론·시간: 위 선행 기준에 맞지 않는 최초 경보 수를 중계 드론의 누적 관측 시간으로 나눈 값.
- Brier: 확률 오차의 평균제곱. 작을수록 좋다. 희귀 사건에서는 항상 낮게 예측해도 작아질 수 있어 단독 판정 금지.
- 확률 신뢰도·ECE: 같은 확률 구간의 실제 사건 비율과 예측 확률의 차이. ECE는 구간을 나누는 방법에 따라 달라진다.
- 입력 자격 상한: 단절 3~7초 전에 유효 관측이 한 번이라도 있었던 사건 비율. 완벽한 예측기를 가정한 가능한 상한이며 달성 재현율이 아니다.
- %p: 두 백분율의 차이. 60%→65%는 +5%p이며 상대 상승은 약 8.3%다.

동일 지도에서 대칭 방향 링크·인접 시각·간섭 비행은 독립 표본이 아니다. 인접·중첩 지도는 기존 공간 그룹으로 함께 묶는다. 수십만 관측을 모두 독립으로 취급해 좁은 신뢰구간을 주장하지 않는다. 결과에는 공간 그룹 단위 짝지은 재표집을 보조적으로 사용한다.
