# 예측 성능 우선 재구성 v8

2026-11-02 학습·비교·독립 개발 확인 완료. 원래 v5·v6·v7 코드·가중치·지도 분할을 보존했다. 봉인된 최종 평가 지도 32개는 열지 않았다.

**판정: 예측 순위 성능 향상 확인. 실사용 경보 목표 미충족. 실제 장비 검증 미실시.**

| 독립 확인 14지도·42비행 | 기존 v7 64회 | 새 후보 |
|---|---:|---:|
| 공통 5초 AP | 56.28% | 65.21% |
| 공통 3~7초 AP | 23.52% | 33.13% |

선정 후보는 `expanded_lgbm_planned_energy`. 공개 경로·통신 이력·관측 품질을 사용하는 LightGBM이다. AP는 경보 적중률과 다르다. 보정 문턱의 확인 성적은 경보 정밀도 83.45%, 사건 재현율 2.31%, 오경보·늦은 경보 0.68회/중계 드론·시간이다. 재현율이 낮으므로 실사용 경보를 자동 활성화하지 않는다.

실시간 실행은 `runtime_stable.load_research_candidate` 또는 `StableLocalForecast`를 사용한다. 배치와 같은 정밀도로 공개 경로를 계산한다. 전체 한 비행의 지원 링크 예측 10,355개에서 특징·확률·경보가 일치했다. 기본 `runtime.py`는 동결된 원본으로 남겨 감사 가능성을 유지했다.

목표는 정확한 선행 경보이다. 현재 연결된 링크의 첫 단절뿐 아니라 회복 후 재단절도 다루는 시간 구간별 정답을 사용한다. 기존 5초 첫 단절 지표도 같은 관측에서 계속 비교한다.

## 수행한 순서

1. 원본 무결성·공간 분할·시간 정렬 확인.
2. 기존 학습 지도 기록을 재사용하되 현재 공간 분할에서 학습인 지도만 허용.
3. 새 학습 지도 79개와 개발 검증 지도 44개에서 동결된 v7 정책의 새 비행 수집.
4. 예측기를 PPO와 분리해 학습. 시간 이력 신경망과 LightGBM 비교.
5. 이동·통신 이력, 결측·경과 시간, 현재 지도 특징을 보완. 선택적 유휴 채널 에너지 관측 실험은 실제 간섭 위치·미래 작동 시각을 입력하지 않음.
6. 모델 선택, 확률 보정·경보 문턱 결정, 마지막 확인 자료를 공간적으로 분리.
7. 개발 목표를 못 맞추면 신뢰 경보를 자동 활성화하지 않음. 점수뿐 아니라 놓침·오경보·선행시간·입력 유효 비율을 보고.

개발 목표 예: 선행시간 3초 이상, 경보 정밀도 90% 이상, 사건 재현율 80% 이상, 오경보·늦은 경보 1회/중계 드론·시간 이하. 교수 지정치나 이미 달성한 수치가 아니다.

기체와 무선 모듈이 아직 정해지지 않았다. 시뮬레이션 지표 통과만으로 실사용 무결함을 보장하지 않는다. 최종 평가 32개 지도는 모델·경보를 동결하기 전에는 사용하지 않는다.

## 연구 근거

- 확률 보정은 독립 자료로 검증한다. 순위 성능 개선과 같은 의미가 아니다: [Guo et al., ICML 2017](https://proceedings.mlr.press/v70/guo17a.html).
- 시간 이력의 합성곱 모델을 후보로 비교한다. 이 문제에서 우수하다는 가정은 하지 않는다: [Bai et al., TCN](https://arxiv.org/abs/1803.01271).
- 클래스 가중치가 확률 추정에 미치는 영향을 고려해 기본 실험은 실제 사전 확률을 유지한다: [LightGBM 공식 파라미터 문서](https://lightgbm.readthedocs.io/en/v4.6.0/Parameters.html).
