# 차폐 기반 선행 경보

`forecaster.predict`는 편대의 현재 계획과 그 시점까지 실제 수신한 RF에서 다음 수색망 단절을 예측한다. `runner.FlightWarnings`가 기존 비행 루프에서 호출한다.

## 입력과 계산

1. **3초 제어 경계**에서 기존 PPO가 제안한 보정을 기존 공동 이동 계획기에 전달한다. 이 계획은 적용 전 안전 제약을 반영한 예상 궤적이다.
2. **그 사이의 1초 경계**에서는 이미 발행된 편대 이동 경로를 사용한다. 전송 완료·수신이 일어난 프레임까지만 비컨과 RF를 읽는다.
3. 향후 8.5초를 0.5초 간격으로 표본화한다. 지도 손실과 수신 전력·잡음으로 링크 여유를 계산한다. 수색기 쌍 사이에서 가능한 직접·우회 경로를 모두 비교한다. 현재 연결로 추정되는 상태에서 새로 1초 이상 이어질 단절을 평가한다.
4. 수신기가 낸 RF 보고가 부족하면 그 수신기의 링크 여유를 넓은 범위에서 시험한다. 로컬 RF가 없으면 경보 점수를 비운다. 최신 비컨을 받지 못한 수색기의 항법 위치는 공유 계획에서 얻는다.
5. 각 링크 여유 가정에서 건물 추가손실을 제거하거나 현재 값으로 고정해 연결이 유지되는지 확인한다. 두 대조에서 회복되는 단절에는 더 높은 점수를 준다. 나머지 단절도 낮은 가중치로 경보 대상에 남긴다.

## 재배치에 전달할 정보

| 필드 | 의미 |
|---|---|
| `shield_score` | 3초 이상 7초 미만 내 수색망 단절 점수. 문턱은 별도 보정 자료에서 선택한다. |
| `short_score` | 0.5초 이상 3초 미만 내 급박한 단절 점수. 선행 탐지 평가와 구분한다. |
| `onset_in_s` | 모델이 예상하는 대표 단절 시작까지 남은 시간 |
| `building_support` | 건물 손실을 제거해 연결이 회복되는 예측의 가중 지지도 |
| `changing_building_support` | 건물 손실을 현재 값으로 고정해 연결이 회복되는 예측의 가중 지지도 |
| `critical_links` | `explain=True`일 때 명목 그래프의 단절 성분 사이에서 사라진 링크와 해당 차폐 손실의 변화량 |
| `status`, `missing_search_beacons`, `unknown_rf_receivers` | 점수를 산출한 관측 조건과 수신 공백 |

점수는 사전에 정의한 링크 여유 가정에서 얻은 위험 지지도다. 보정된 실제 단절 확률과 단위가 다르다. 이동 제어기가 활용하려면 기존 명령과 실행 가능한 각 대안에 이 평가를 적용하고, 예상 단절과 초기 이동의 안전성을 비교해야 한다. 이번 시험에서는 같은 실제 궤적을 유지하면서 경보만 평가했다.

1초 경보의 보조 실험에서는 `tracking.LeadTracker.update`에 예측 시각, `shield_score`, `onset_in_s`를 전달한다. 예상 단절 시각이 두 번 연속 비슷할 때 경보를 내고 같은 예상 사건의 경보를 묶는다. 주 비교와 별도로 보정한 설정은 `artifacts/tracking_freeze.json`에 기록한다.

중앙 공동 계획기가 현재 편대 항법 상태를 제공해야 한다. 미래 채널 정답, 간섭원 상태, 실제 미래 비행 경로는 입력에 포함하지 않는다. 예측의 1초 주기와 이동 제어의 3초 주기는 별도로 유지된다.
