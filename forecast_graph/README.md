# 예정 경로 공유·시간 그래프·물리 보정 실험

기존 코드·모델·보고서를 보존하는 별도 예측 학습 실험이다. PPO 자료 생성 정책을 고정하고 예측기를 지도학습한다. 실행 상태는 프로젝트 루트의 `03_경로공유_그래프예측_현황.bat` 또는 `python -B -m forecast_graph.status`에서 확인한다.

**2026-11-02 23:15 완료.** 모델10개 학습·새42비행 확인·보존·실시간 검사를 마쳤다. 두 과제의 개발 경보 목표는 미충족이다. [최종 보고서](RESULTS_20261102.md)를 따른다. 임무 경로 보완의 후속 대조는 별도 `forecast_navigation`에 보존한다.

## 구현

- 기존128B·1Hz 비콘 안에 현재 발행 명령의 예정 경로와 수신한 RF 보고를 넣는다. 실제 수신한 패킷만 입력한다.3초 이후 경로는 현재 목표에 따른 잠정 경로이며 실제 미래 위치·정책 명령은 입력하지 않는다.
- 노드34/링크4항목의 네 시점 그래프, 메시지 전달2회와GRU로 통신 관계를 유지한다.
- 공개 지도·계획/등속 가정의0~8초 물리 참조와 학습한 SINR 잔차를 결합한다. 보정된 미래 채널과 연결 경로의 참고값이 장애 예측에 연결된다.

## 비교 경계

훈련245비행94,080표본. 선택45·보정45비행. 같은 첫 중계드론의 모든 유효1Hz 시점을 사용한다. 모델과 문턱을 고정한 뒤 별도42비행으로 확인한다. 이전 보고서의 전체 중계드론 평균과 직접 차감하지 않는다. 물리 링크 단절과 패킷 서비스 장애는 서로 다른 과제다.

그래프3구성×고정 난수2개와 기존/공유 입력 트리2구성×2개, 총10개를 학습한다. 트리 대조군은 기존 입력728/432항목을 그대로 유지해 새 정보의 효과를 같은 표본·설정에서 확인한다. 원래 최종 지도32개는 봉인한다.

## 연구용 API

```python
from forecast_graph.runtime import load_link, load_service
link = load_link(city, n_drones, n_search, nominal=nominal_xy)
service = load_service(city, n_drones, n_search, nominal=nominal_xy)
```

각 API에 매0.5초의 첫 중계드론 로컬 `[N,48]` 값·마스크, `[N,9]` 발행/수신 명령, `[N,6]` 측정 에너지를 전달한다. `received_packets`에는 실제 수신한128바이트 메시지만, `own_packet`에는1Hz 자기 송신 메시지를 전달한다. `codec.pack`이 명시적 형식이다. 자기 외 드론의 비공개 상태나 실패한 수신의 SINR은 입력하지 않는다.

20초 이력 뒤1초마다 위험을 출력하고 경보 시작은21초다. 필수 RF 결측은None이다. 자동 경보와 PPO 자동 교체는 비활성이다. 실제 무선 장비·탑재 지연·현장 예측 성능은 별도 검증 대상이다.

완료된 동결 실험을 덮어쓰지 않는다. 복구가 필요하면 기존 모델·문턱을 유지한 `compare`/`post` 단계만 검사해 재개한다.
