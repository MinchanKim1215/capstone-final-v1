# 캡스톤 디자인 II — 경로 보완 예측 비교

2026-11-03 학습·새42비행 비교·실시간 실행·무결성 검사를 완료했다. 상세 결과는 `RESULTS_20261103.md`다. 사전 순위 우수 혼합 후보의3~7초 AP는 물리33.40%→36.87%, 서비스12.92%→21.75%다. 서비스 기본 경보의 선행 탐지율15.62%·정밀도49.02%로 실사용 경보 목표에는 미달했다.

연구용 API의 경보 기준 선정과 위험 순위 우수 후보는 다르다. 물리 API는 사전 경보 기준으로 선정한 기존 대조 트리를 유지한다. 서비스 API는 보완 경로 혼합을 사용한다. 자동PPO 교체와 신뢰 경보는 활성화하지 않았다.

V11의 경로 공유·시간 그래프·물리 잔차 모델을 보존하고 잠정 경로만 보완한 별도 연구다. 실시간 첫 중계드론 관측과 실제 성공한128바이트 비컨 수신만 사용한다. 원래 최종32지도는 열지 않는다.

실행 중에는 `artifacts/status.json`이 실제 단계를 표시한다. 모든 작업이 완료되면 `RESULTS_20261103.md`, `artifacts/final_results.json`, 세 비교 그림, `artifacts/audit.json`, `artifacts/runtime_checks.json`을 함께 확인한다. 모델 학습 완료만으로 전체 평가 완료나 실사용 성능 확보를 뜻하지 않는다.

## 비교 설계

- 선택45비행에서 명령 발행 후3~7초 경로 RMSE를 검사했다. 사전30% 감소 기준을 통과한 뒤 추가 학습을 허용했다. 경로 오차 감소는 예측 향상률과 구분한다.
- 원래/보완 경로 각각 난수2개, 같은 초기 가중치·94,080훈련 표본·정답·추가6,000업데이트·선택 표본으로 비교한다.
- 물리6후보·서비스5후보를 선택/보정한 뒤 코드·모델·경보 문턱을 고정한다. 이후 알려진14지도에서 새로운 난수42비행을 생성한다. 확인 자료에 맞춘 재선정은 금지한다.
- 이전 V11 선정 모델과 순위 우수 모델을 그대로 비교한다. 약한 기준만으로 개선을 주장하지 않는다. 동일 학습량의 원래/보완 경로 차이가 경로 개선의 대조 효과다.
- PPO는 기존 정책으로 고정한다. 이번 네 예측 모델은 지도학습한다. 자동PPO 교체나 실제 장비 경보는 활성화하지 않는다.

## 연구용 API

`runtime.load_link`와 `runtime.load_service`는 동결한 선정 모델·보정 정책을 검증해 읽는다. 공개 지도/임무와 모델에서 확인한 드론 수가 필요하다. 매0.5초의 로컬 관측, 실제 성공한 비컨 및 자신의 발행 비컨을 시간 순서로 공급한다. 경로 확장 패킷에서 원래/보완 계획을 함께 복원하며 추가 전송을 가정하지 않는다.

비컨의 보완 경로는 시뮬레이터 임무 제어기의 현재 계획 상태에서 산출한다. 실제 분산 드론에서 해당 제어 상태를 동기화하고 같은 비컨을 생산하는 장비 통합은 검증하지 않았다.

20초 관측 후1초마다 위험도를 계산한다. 경보 검사는21초부터 시작한다. RF 결측은 `None`이다. 실제 장비 검증과 독립 경보 목표를 충족하지 않았으므로 `trusted_alarm_enabled=False`다.

## 근거·보존

`protocol.json`, `training_plan.json`, `comparison_spec.json`은 사전 설계다. `freeze.json`은 확인 전에 고정한 소스·가중치·문턱이다. `delivery_manifest.json`은 완료 및 시각 검토 후 생성한다. 원본 RF·이동·패킷과 기존 V8/V9/V10/V11 코드는 변경하지 않는다.
