# 20초 드론·링크 예측 실험

사용자 선택인 **탐지율 우선·오경보 약4회/드론·h 허용**을 반영한 별도 연구 실험이다.

현재 역할: 개별 드론·방향성 링크의20초 이력을 유지하고 그래프를 직접 학습한다. 기존480항목 집계 보정 모델과 구분한다. 기존 파일·모델·현재 연구 프로필은 보존한다.

- 자료: 훈련245비행, 모델 선택45비행, 확률·문턱 보정45비행.
- 대조: 짧은 이력 일반 학습 / 짧은 이력 사건 학습 /20초 이력 사건 학습. 같은 초기 가중치·배치 순서·2400업데이트·각 두 난수.
- 확인: 모델·소스·문턱 고정 후 생성하는 새42비행. 알려진14지도, 세 간섭 조건. 원래 최종32지도는 미사용.
- 지표: 사건 발생3초 이상·7초 미만 전 최초 경보의 사건 탐지율. 정밀도·실제 오경보를 함께 보고한다.
- 비용: 보정 자료에서FA4/h를 적용한다. 실제 이후 비행의4/h 하드 상한을 보장하지 않는다.

진행 확인: 루트의 `07_20초그래프_학습현황.bat`. 완료 후 `RESULTS_20261103.md`와 `artifacts/final_results.json`을 기준으로 결과를 확인한다. 자료 구성·GPU 학습·새 비행·실제API 검증·전체 감사가 끝나야 완료로 표시한다.

연구용 실행 경로:

```python
from forecast_temporal.runtime import load_service
stream = load_service(city, n_drones, n_search, nominal)
```

검증 완료된 사전 선정안만 내보낸다.128바이트 실제 수신 비컨, 로컬 관측과 마스크·현재 발행 의도·측정 에너지를 매0.5초 전달한다.20초 이력을 모은 후1초 주기로 위험도를 반환한다. RF 결측은 위험도None이다.

새 예측기 학습은 지도학습이다. 기존PPO 자료 생성 정책을 고정했다. 실제 장비 검증, 신뢰 경보와 자동PPO 교체는 활성화하지 않는다. 새 모델의 성능 향상은 결과를 확인하기 전에 전제하지 않는다.
