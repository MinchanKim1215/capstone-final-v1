**1~6단계 개선 뒤 LightGBM–Transformer 비교: 실행 기준과 현재 상태**

2026-10-29. 사용자가 사진으로 제시한 여섯 방향을 기준으로 정리했다. 아래의 개발 목표와 후보 크기는 교수 지정값이나 달성값이 아니다.

진행 순서는 신뢰 기준 → 동일 관측 실패 진단 → 데이터 보강 → 예측 목적과 공동학습 점검 → 확률 보정 → 모델 크기 비교다. 데이터·정답·평가·확률 보정에서 공통으로 적용할 수 있는 개선은 LightGBM과 Transformer 모두에 적용한다. 이후 개선 전/후와 알고리즘 차이를 각각 비교한다.

| 단계 | 현재 완료한 작업 | 남은 작업 |
| --- | --- | --- |
| 1. 신뢰 기준 | 경보 정밀도 90%, 최소 3초 선행 사건 재현율 80%, 오경보 1회/드론·시간, 최소 경보 10건을 개발 목표로 기록 | 표본 수와 지역별 편차를 함께 보고 최종 기준의 타당성 확인 |
| 2. 실패 진단 | 같은 관측 8회에 사전학습·PPO 176/190·LightGBM 적용, 사건별 판단 시점/지원/라벨 확인, 사건 전 점수 요약 | 실제 RF 전조·비콘 노후화·차폐·재머 전환별 원인 분해 |
| 3. 데이터 | 고정 지도학습 자료 192회와 원본 SHA 확인, 166지역 및 head별 양성·간섭·방향 분포 집계 | 부족한 조합과 놓친 시작 사건을 훈련 지역에서 보강. 추가 PPO 경험은 별도 출처로 관리 |
| 4. 학습 목적 | 사전학습 best와 제어 best 선택 기준 차이 확인, 동일 관측 비교 기준 마련 | head/사건 단위 추출 실험, 동일 시작 모델에서 예측기 고정+PPO 대 공동 PPO 비교 |
| 5. 확률 보정 | 4개 공간 fold에서 6지역 보정/2지역 평가, Brier·ECE·포함 관계 확인 | 포함 관계를 유지하는 보정 후보와 보정 후 사건 경보를 따로 검증 |
| 6. 모델 크기와 비교 | 현재 모델과 과거 LightGBM의 기준 결과 확보 | 같은 훈련 자료에서 새 LightGBM, Transformer 32/2층, 64/2층, 필요시 128/3층 학습·비교 |

현재 추가 진단에서 확인한 우선순위는 다음과 같다.

- 5초 경보의 1,779개 사건 중 368개에는 현재 3초 판단 격자상 ‘발생 3~5초 전’ 판단 시점이 없었다. 판단 시점이 있는 1,411개 사건 중 공통 관측 지원이 있는 사건은 1,180개다. 이 결과는 해당 경보 주기와 사건 집합의 성질이다.
- 8초 경보에서는 1,779개 사건 모두에 ‘발생 3~8초 전’ 판단 시점이 있었고, 공통 관측 지원 사건은 1,573개다. 현재 자료는 모델 크기 외에 주기·지원 범위·라벨 시간 정렬도 먼저 살펴볼 이유를 제공한다.
- 미래 정답을 그대로 경보로 사용한 진단의 사건 적중은 5초 627건, 8초 1,437건이었다. 이는 저장된 라벨과 최초 경보 규칙의 정렬 검사이며, 실제 예측 성능이나 모든 모델의 이론적 최대치가 아니다.
- 공간 교차 적합 보정에서 LightGBM의 5초 위험 Brier는 0.009680에서 0.008826으로 낮아졌다. Transformer 176은 0.009672에서 0.009676으로 거의 같았다. 확률 보정만으로 모든 모델의 놓친 사건이 해결된다는 근거는 없다.
- 독립 head 보정은 Transformer 176에서도 포함 관계를 15개 표본에서 위반했다. 이 보정기를 그대로 운용에 넣지 않았다.
- 지도학습 192회는 166개 훈련 지역을 모두 포함하지만 지역×두 방향×세 간섭 조건 996개 중 192개 조합을 포함한다. 부족한 모든 조합을 무조건 채울 필요는 없으며, 누락 사건과 조건별 실패를 보고 우선순위를 정한다. 이후 PPO는 별도의 추가 비행 경험을 계속 수집한다.

새 모델 비교에서는 다음을 고정한다.

| 비교 항목 | 실행 기준 |
| --- | --- |
| 원천 자료 | 동일 훈련 비행, 동일 공간 그룹 분할. 정책별 수집 출처와 seed 기록 |
| 사용 가능한 정보 | 동일한 과거 관측·지도·알려진 의도만 허용. 트리는 통계 특징, Transformer는 시계열 표현을 쓸 수 있으나 미래 정보는 공통 금지 |
| 정답 | 지속 1초 단절, 현재 정책하의 실제 결과, 예측 시간 구간·지원·검열 정의를 명시 |
| 판단 주기 | 먼저 같은 주기끼리 비교. 0.5/1초 갱신 후보는 라벨·시각 계약까지 함께 정의하는 별도 실험 |
| 학습 조건 | 두 알고리즘을 같은 새 자료로 재학습. 탐색 횟수·시간·seed 공개. 과거 서로 다른 훈련 이력으로 아키텍처 우열을 단정하지 않음 |
| 모델 선택 | AUROC/AP뿐 아니라 정밀도·3초 선행 사건 재현율·오경보·선행시간·지역별 성능을 함께 사용 |
| 확률 보정과 경보 | 보정·문턱을 맞춘 지역과 평가 지역 분리. 지원 불가 사건도 사건 재현율 분모에 유지 |
| 제어 결합 | 예측 자체의 결과를 먼저 확정한 뒤 같은 안전 이동기와 제어 인터페이스에서 재배치 효과 비교 |
| 최종 평가 | 개발 설정을 고정한 뒤 미사용 테스트 평가. 이미 checkpoint 선택에 쓴 8개 진단 맵은 독립 최종 평가로 부르지 않음 |

공동 PPO가 예측을 훼손한다는 가설은 아직 입증되지 않았다. 현재 동일 관측의 5초 위험 AP는 사전학습 2800의 0.3658보다 PPO 176의 0.3835가 높다. 따라서 관측한 결과를 근거로 손실·학습률·고정 여부를 비교하며, 원인을 미리 확정하지 않는다. LightGBM 자체를 현재 신경망 PPO와 같은 방식으로 역전파 학습한다고 설명하지 않는다.

이번에 실제로 실행한 것은 CPU 진단과 기준 정리다. 큰 Transformer 재학습·예측기 고정 PPO 비교·새 LightGBM 재학습은 아직 시작하거나 자동 예약하지 않았다. 기존 GPU run과 예정된 검증은 원래 설정으로 계속 진행 중이다.
