**최종 예측·재배치 구성 후보와 권장 실험 순서**

작성: 2026-10-29. 이 문서는 설계 제안이다. 현재 CUDA 학습, 예측기, 보상, 지도 분할을 변경하거나 아래 후보를 새로 학습시키지 않았다. 판단 근거는 v5 소스와 동일 관측 예비 검증이며, 후보 기법의 효과를 우리 환경에서 검증했다는 의미는 아니다.

권장 중심 구조는 다음과 같다. 지도·전파·안전 이동기를 보존하고, 독립 검증으로 고른 예측기가 위험 확률·시간 정보를 내며, PPO가 제한된 재배치 후보를 선택한다. 사람에게 보여주는 사건 경보는 별도의 보정·오경보·선행시간 검증을 거친다. 첫 기준은 예측기 고정 + PPO로 잡고, 공동학습은 예측 품질과 제어 양쪽에 이득이 확인되는 추가 실험으로 둔다.

최종 예측기를 지금 Transformer나 LightGBM으로 확정하지 않는다. 현재 LightGBM은 가장 강한 순위 성능 기준선이지만 충분한 조기 경보를 입증한 모델은 아니다.

**확인된 출발점**

| 고정 관측에서 평가한 예측기 | 5초 위험 AP | 3–4초 시작 AP | 3–7초 시작 AP |
| --- | --- | --- | --- |
| 사전학습 Transformer 2800 | 0.3658 | 0.1046 | 0.1532 |
| 공동 PPO Transformer 176 | 0.3835 | 0.1170 | 0.1537 |
| 공동 PPO Transformer 190 | 0.3825 | 0.1151 | 0.1568 |
| LightGBM | 0.4736 | 0.1214 | 0.1875 |
| 공간 교차 적합 단순 혼합 | 0.4654 | 0.1194 | 0.1817 |

모두 같은 링크·시점·정답의 공통 지원 범위다. 관측 경로가 다른 176 자체 비행의 AP 0.5081과 직접 비교하지 않는다. 8개 맵은 이전 checkpoint 선택에 사용됐고 학습 데이터·예산도 모델마다 다르다. 독립 최종 평가나 아키텍처 자체의 우열 증명으로 해석하지 않는다.

확률 0.5에서 5초 위험의 실제 양성 표본 2,101개 중 두 모델이 함께 잡은 것은 458개, LightGBM만 잡은 것은 573개, Transformer 176만 잡은 것은 12개였다. 이는 이 문턱에서 상보성이 크지 않다는 단서이며 모든 문턱·결합 방법에서의 한계를 증명하지 않는다. 혼합은 Brier 오차가 더 낮았으므로 순위와 확률 오차는 별도로 판단한다.

**크기보다 먼저 바꿔 볼 운영 구조**

현재 RF 관측은 0.5초 주기이고 예측·경보 판단은 3초 제어 주기에 결합돼 있다. 새 실험에서는 이동 명령은 3초로 유지하고 위험 확률만 0.5초 또는 1초마다 갱신할 수 있다. 관측 뒤 다음 판단까지의 대기를 줄일 가능성이 있지만, 계산량과 오경보도 늘 수 있다. 라벨 시각, geometry/intent의 현재 시각, 1초 지속 단절 정의를 함께 검증해야 한다. 주기를 줄이는 것만으로 관측되지 않은 전조가 생기는 것은 아니다.

현재 양성/음성 추출은 주로 risk_5s 기준이다. 단절 시작 head별·사건별 표본, 놓친 사건 이전 구간, 오경보가 난 어려운 정상 사례를 균형 있게 확보하는 것이 모델 확대보다 먼저다. 수십만 개의 인접 프레임은 수십만 개의 독립 단절 원인을 뜻하지 않는다. 현재 사전학습 corpus와 PPO 중 추가로 쌓이는 경험도 구분해서 관리한다.

예측 의미는 다음 중 무엇인지 명확히 한다.

- 현재 정책을 실행할 때 실제로 발생할 단절.
- 재배치하지 않았을 때 발생할 단절.
- 특정 재배치 후보를 실행했을 때 발생할 단절.

후보 행동 조건부 예측은 재배치와 가장 직접적으로 연결될 수 있지만, 다양한 행동의 결과 데이터와 통제된 시뮬레이션이 필요하다. 현재 관측에서 나온 실제 결과 라벨을 그대로 반사실 정답으로 부르면 안 된다.

**재배치 알고리즘과의 연결**

| 구성 | 권장 역할 | 판단 |
| --- | --- | --- |
| 현재 공유 Actor + 중앙 Critic PPO | 5개 중계 드론의 제한된 이산 후보 선택 | 우선 유지한다. 예측기 개선 효과를 분리해서 볼 수 있는 기존 기준이다. 중앙 critic은 학습용이며 운용 지휘소를 새로 두는 뜻이 아니다. |
| 예측기 고정 + PPO | 좋은 예측기를 제어 보상 때문에 훼손하지 않는 기준 | 가장 먼저 완결할 결합 경로로 권한다. 트리·신경망 모두 같은 의미의 예측 인터페이스를 사용할 수 있다. |
| 예측기 + 공동 PPO | 제어와 예측의 상호 개선 | 현재 구현을 기준 결과로 보존한다. 같은 관측의 예측 품질과 실제 제어 양쪽의 개선이 있을 때 채택한다. 트리 자체가 일반적인 PPO 역전파로 학습되는 것은 아니다. |
| 물리 기반 후보 선택 | 예측 도움 없이 가능한 성능의 기준 | 기존 후보 생성은 이미 지도·전파 계산을 사용한다. '예측 없음'은 '재배치 없음'과 구분한다. |
| 예측 위험을 이용한 MPC | 제한된 미래 후보를 비교하는 제어 대안 | PPO의 필요성과 설명 가능성을 비교할 후보다. 모델 오차·안전 제약·계산 비용을 평가하며 현재 물리 후보 생성과 중복되는 역할을 구분한다. |
| SAC/TD3/MADDPG 등으로 교체 | 행동 공간·협력 구조 자체가 병목일 때 검토 | 현재 예측 부족을 해결할 첫 수단으로 권하지 않는다. 연속 행동화와 안전 이동 연동을 바꾸면 새 연구 범위가 된다. |
| 공통 안전 이동기 | 장애물·분리 거리·속도 제한 | 예측기와 제어 알고리즘이 바뀌어도 독립 검사를 유지한다. 예측 확률 하나로 안전 제약을 해제하지 않는다. |

링크 단절과 임무 네트워크 단절도 구분한다. 우회 경로가 있는 링크와 수색 3기의 연결을 끊는 핵심 링크는 제어상 중요도가 다르다. 필요한 경우 임무 연결 위험을 별도 출력으로 학습하되, 사용자에게 보여주는 링크 경보와 네트워크 경보의 단위·분모를 바꾼 사실을 명시한다. 경보를 묶어서 수를 줄인 것을 예측 정보 자체의 향상으로 보고하지 않는다.

**후보를 끝까지 가져가는 순서**

1. 현재 v5 학습과 예정된 전체 검증을 완료해 기준 결과를 보존한다. 최종 holdout은 개발을 마칠 때까지 열지 않는다.
2. 사건 전 점수·정보 유효성·지도·간섭별 실패와 양성 표본 구성을 분석한다. 0.5/1초 예측 주기와 현재 3초 주기를 동일 사건 정의로 비교할 작은 실험을 설계한다.
3. 같은 훈련 지역·라벨·관측 계약으로 LightGBM과 현재 규모 Transformer를 예측 전용으로 학습·보정한다. 사건 재현율·오경보 조건을 모델 선택에 명시한다.
4. 예측 목표와 데이터가 정리된 뒤 Transformer 64, 필요시 128을 비교한다. 크기·이력·목표를 모두 동시에 바꿔 원인을 알 수 없게 만들지 않는다.
5. 가장 좋은 단독 후보 두 개만 남겨 상보성이 확인되면 혼합·잔차·게이팅을 검토한다. 단독이 가장 좋으면 단독을 선택한다.
6. 충분히 압축된 후보만 고정 예측기 + PPO에 연결한다. 동일 시작 정책·비행 조건·학습 예산을 맞추고 여러 seed로 비교한다. 이후 공동학습을 추가 비교한다.
7. 모델 선택과 확률 보정/경보 튜닝은 공간 그룹으로 분리하거나 교차 적합한다. 전체 검증 뒤 모델과 경보 규칙을 고정하고 미사용 최종 테스트로 평가한다.

예측 모델을 바꿀 때마다 256 update PPO를 모두 다시 돌리면 비용이 크게 늘어난다. 먼저 고정 관측의 예측 단계에서 후보를 줄이고, 최종 2~3개만 제어 실험에 연결하는 편이 실용적이다. 예측 합격 기준을 만족하는 후보가 없으면 가장 높은 AUROC를 낸 후보를 '신뢰 가능'으로 승격하지 않는다.

**배포·설명에서 유지할 조건**

확률 보정, 충분한 선행시간의 사건 재현율, 오경보 빈도, 지역별 실패, 판단 불가 비율을 함께 공개한다. 신경망 attention만으로 물리적 원인을 증명했다고 설명하지 않는다. 실제로 받은 비콘과 알려진 지도에서 확인할 수 있는 신호 악화·차폐·정보 노후화 근거를 구분해 제시한다. 전조 없이 새로 발생하는 간섭을 포함해 모든 상황에서 높은 예측 성공률을 보장할 수는 없다.
