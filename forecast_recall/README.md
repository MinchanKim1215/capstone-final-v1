2026-11-03 학습·새42비행 평가·무결성·실시간 검사를 완료했다. 기본 운영점은 기존11.49%→선정안10.92%로 탐지율이 높아지지 않았다. 정밀도40.00%→52.78%, 실제오경보1.41→0.80/h였다. 보정FA5 탐지 우선 운영점은24.71%→31.61%로 높아졌고, 실제오경보4.05→4.24/h·정밀도33.33%→38.78%였다. 양쪽 모두 실사용 신뢰 목표에 미달한다.

기존V12의 서비스 장애 선행 탐지율15.625%(25/160건)를 출발점으로 한 별도 실험이다. 기존 코드·가중치·보고서를 보존한다. 새42비행에서 기존 모델과 새 후보를 같은 조건으로 비교한다. 이전15.625%와 새 비행 수치를 직접 빼지 않는다.

## 학습 구성

- 훈련245비행에서 무작위 시간 표본125,440개와 사건 전 구간2,393개를 포함한148,949시점을 사용한다.
- 기존 경로·시간 그래프·물리 모델의 가중치를 고정한다. 현재 표현과 출력에 작은 보정 예측기를 학습한다.
- 일반BCE 대조군, 사건 단위 손실,20초 과거 관측을 더한 사건 단위 손실을 각각 고정 난수2개·4,000업데이트로 비교한다.
- 체크포인트를 실제 최초 경보의 사건 탐지율·오경보 예산으로 선택한다. 정밀도·탐지율·경보 개수의 기존 개발 목표는 그대로 기록한다.
- 기존 모델·문턱, 문턱만 조정한 대조군, 새 세 모델과 두 혼합 모델을 모두 비교한다.

## 연구용 실행

`runtime.load_service(city, n_drones, n_search, nominal)`는 실제 동결한 선정 모델과 보정 문턱을 읽는다. 매0.5초의 로컬 관측·마스크·이미 발행한 의도·측정 에너지, 실제 받은128바이트 비컨과 자신의 비컨을 시간 순서로 전달한다.20초 관측 후1초마다 위험도를 계산한다. 원래3초 선행 사건 정의와 히스테리시스를 유지한다. RF 결측은None을 반환한다.

예측기 학습은 지도학습이다. 자료 생성PPO는 고정한다. 물리 링크 예측기를 새로 학습한 실험과 구분한다. 실제 장비 검증·신뢰 경보·자동PPO 교체는 활성화하지 않는다. 원래 최종32지도는 열지 않는다.

보조FA1/3/5 운영점은 주 모델·문턱 고정 후, 새 예측 결과를 보기 전에 보정 자료에서 별도로 고정한다. 실제 오경보 값을 함께 보고하며FA3/5를 기존FA1 목표 달성으로 표시하지 않는다.

`runtime_options.load_service(city, n_drones, n_search, nominal, budget_per_hour=5)`로 사전에 보정한FA5 탐지 우선 옵션을 불러온다. 추가 인터페이스 구현은 결과 확인 후 진행했으며, 문턱은 사전 보정 계획의 고정값이다. 기본 문턱은 자동 교체하지 않는다. 보정 경보50개를 충족하는 옵션만 허용하며, 신뢰 경보·자동PPO 교체는 비활성이다.
