**예측 성능 개선 1차 실험**

진행 중인 `drone_forecast_joint_training`의 코드·보상·PPO·가중치를 바꾸지 않는 별도 예측 실험이다. LightGBM 비교는 보류한다.

이번 구현은 다음 단절 시점 분포를 학습한다. 0~8초를 0.5초씩 나눈 16개 구간과 ‘8초 안에 시작 없음’을 구별하고, 화면에서는 0~2·2~4·4~6·6~8초 확률로 합칠 수 있다. 1초 이상 지속하는 다음 링크 단절이 정답이며, 기존 ‘구간 안의 임의 단절’과는 다른 목표다. 반복 단절에서도 이 차이를 검사한다.

기록된 0.5초 RF 관측으로 1초 예측 시점의 과거 40프레임을 구성한다. 지도 특징은 그 시점까지 받은 관측과 알려진 의도로 다시 계산한다. 미래 위치·미래 간섭·정답은 추론 입력으로 주지 않는다. 단절 지속 여부를 끝까지 확인할 미래가 없는 끝부분을 정상 음성으로 학습하지 않는다.

현재 Transformer 32차원/2층 encoder를 사전학습 2800 checkpoint에서 초기화하고 시간 구간 출력층을 추가한다. 기존 예측 head의 BCE 보조 손실도 유지한다. 기존 가중치와 새 실험 checkpoint 형식은 별개이며 기존 PPO에 바로 주입하지 않는다. 예측 갱신을 늘리는 오프라인 실험이며 실제 이동 명령은 기존 run의 3초 주기 그대로다.

첫 단계 자료는 기존 훈련 192회·검증 8회다. 별도 CPU 한 스레드와 낮은 프로세스 우선순위를 사용하며 GPU는 숨긴다. 자료 준비 뒤 예측 전용 6,000단계 시범 학습과 전체 검증 관측 재생을 진행한다. 원본 hash·공간 분리·출처와 새 소스·설정을 protocol.json으로 고정하며, 중단 시 이 실험의 latest.pt에서 이어간다.

7개 검사에서 모든 시간 구간 경계, 단발/지속 단절 구분, 반복 사건의 첫 시작, 끝부분 검열, 현재 단절 마스크, 미래 관측 미유입, 1초/3초 경보의 동일 관찰 시간 분모, 실제 encoder/출력층 gradient와 checkpoint 복원 출력을 확인했다. 현재 학습 코드는 전달 v5의 불변 파일 966개(Python 161개)와 계속 동일하다.

진행 파일: `runs/next_outage_1s_v1/status.json`, `stdout.log`, `stderr.log`, `history.json`. 완료 결과: `results.json`. 최종 테스트는 사용하지 않는다.

이번 AP는 새로운 ‘다음 사건’ 정답으로 계산한다. 기존 176의 발표 AP와 직접 증감 비교하면 안 된다. 저장된 float16 관측으로 재구성한 지도 입력도 기존 full float32 계산과 완전히 같다고 볼 수 없다. 동일 입력에서 개선 전 모델 재생, 새 조건/PPO 자료 보강, 사건 단위 추출, 경보 문턱·확률 보정, 제어 통합은 후속 검증 항목이다. 첫 결과가 나온 것을 곧바로 예측 성능 향상 입증으로 보고하지 않는다.

CPU 작업도 시뮬레이션 수집 시간에 일부 영향을 줄 수 있다. 실행 파일·원본 연구 소스·현재 CUDA run은 그대로 유지한다. 새 ZIP은 참조와 파일 지문 비교에만 사용했고 실행 중인 폴더에 덮어쓰지 않았다.
