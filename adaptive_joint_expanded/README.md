## 현재 실험과의 관계

- `../adaptive_joint`의 코드·설정·지도 목록·모델을 덮어쓰지 않음.
- 현재 학습이 `completed` 또는 `early_stopped`로 끝나고 실행 잠금이 해제된 뒤 후속 작업 허용.
- 끝난 실험의 임무 완료·안전·PDR·시간 조건을 통과한 정기 평가 중 5초 내 단절 AP가 가장 높은 모델을 초기 가중치로 선택.
- 예측기뿐 아니라 중계 정책·가치망·대형 선택기의 전체 가중치를 엄격히 복원. 데이터 구성이 달라지므로 새 난수·새 Adam 상태로 학습.
- 모델 선택에 쓴 AP는 개발 평가 수치. 독립 최종 성능 향상 증명으로 해석하지 않음.
- 별도 형식 `adaptive-joint-next-event-v7-expanded100`, 실행 이름 `adaptive_v7_expanded100_20261031` 사용.

## 다음 학습 절차

`현재 학습 종료 → 초기 모델·해시 동결 → 준비 상태 갱신 → 기준 경로 검증 → 전체 사전 검증 → 확장 학습`

현재 학습이 중단·실패하면 후속 학습을 시작하지 않는다. 단계별 검사가 실패해도 자동 재시도하지 않는다.
초기 모델이 확정되기 전에는 장시간 후속 학습을 시작할 수 없다.

- 예측 갱신 1초, 미래 8초를 0.5초 간격 16구간과 단절 없음으로 분류.
- 중계 재배치 3초. 네 가지 대형과 기체 수 제약 유지.
- 기본 학습 상한 256회 갱신 × 8비행 = 2,048비행. 기존 조기 종료 조건 포함.
- 기존·추가 학습 지도를 함께 사용. 작은 정기 검증 묶음에도 기존 지역과 새 지역을 섞어 평가.
- 모델·경보 동결 전까지 최종 평가 32개 지역 사용 금지.
