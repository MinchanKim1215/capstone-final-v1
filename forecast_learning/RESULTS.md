# 캡스톤 디자인 II — 차폐 기반 예측 학습과 예방 재배치

동일한 신규 42개 비행에서 3초 이상 7초 미만 선행 탐지율은 V20 58.64%, 학습 후보 59.55%였다. 차이는 +0.91%p, 공간 그룹 재표집 95% 구간은 [-4.85, +3.02]%p다.

## 실제 학습 내용

훈련 전용 245개 지도에서 154,312개 제어 시점의 입력을 만들었다. 3~7초 선행 단절 정답 1,871개와 3초 미만 임박 단절 정답 1,315개가 포함됐다. 단절 구간은 수색기 사이에 직접 또는 중계 연결이 1초 이상 사라진 경우다.

첫 3초는 기존 공동 이동 엔진으로 계산한다. 이후 보정을 유지하는 경로와 명목 경로로 돌아가는 경로를 둘 다 계산했다. 각 경로에 대해 0.5초별 수색망 여유, 건물 손실 제거·고정 시의 여유, 취약 링크 비율, 최신 무선 관측을 모델에 전달했다. 실제 미래 위치와 채널은 정답과 평가에 사용했다.

LightGBM 세 모델을 각각 420회 갱신했다. 명령 유지 경로만 보는 선행 예측, 두 경로를 보는 선행 예측, 두 경로를 보는 3초 미만 예측이다. 보정 45비행과 선정 45비행을 분리하고, 새 난수 42조건을 열기 전에 모델과 문턱을 고정했다.

고정한 선행 설정은 두 경로 가정을 학습한 모델 160회 갱신, 학습 점수 70%와 V20 점수 30%, 경보 문턱 0.1775다. 선정 비행에서는 탐지율 62.25%, 정밀도 69.20%, 오경보·늦은 경보 3.05회/편대·시간이었다.

## 실제 중계 명령을 바꾼 비교

선정 자료의 조건을 충족해 학습 선행 점수를 추가 예방 개입에 사용했다.
기존 V18의 예방·복구 명령은 먼저 적용했다. 추가 개입은 한 대의 보정만 바꾸고 두 경로 가정에서 연결 부족량이 악화되지 않으며 가장 취약한 경로의 부족량이 감소할 때 허용했다. 첫 3초 연결 여유와 학습한 임박 단절 점수도 확인했다.

| 제어 | 새 단절 | 새 단절/비행 시간 | 단절 초/비행 시간 | 기한 내 전달 | 임무 완주 | 안전 위반 |
|---|---:|---:|---:|---:|---:|---:|
| V7 기존 PPO | 220 | 10.28 | 56.89 | 97.56% | 42/42 | 0 |
| V18 기존 예방 | 214 | 9.97 | 53.67 | 97.70% | 42/42 | 0 |
| V21 추가 예방 | 184 | 8.56 | 47.52 | 97.99% | 42/42 | 0 |

V18 대비 새 단절률 차이는 -1.41회/h (95% 구간 -1.89~-0.89회/h)였다. 기한 내 전달률 +0.29%p, 임무 시간 +0.19%, 중계 이동 거리 +0.19%였다.

추가 명령은 115회였고 그중 111회는 실제 수색망이 연결된 상태였다. 첫 명령 분기 직전까지 두 비행의 명령·위치·링크가 일치하며 대안이 이후 12초 동안 연결을 유지한 사례는 7건이었다. 개입 횟수는 피한 단절 수와 구분한다.

실제 이동 비교가 새 예방 제어의 사전 채택 조건을 충족했다.

## 적용 범위

알려진 지도 14개에서 세 간섭 조건의 새 난수를 사용했다. 기체의 현재 항법 상태를 공유하는 공동 계획기를 전제했다. 두 미래 경로는 다음 PPO 선택을 추정하는 가설이다. 실제 장비의 관측 지연과 비컨 중계는 별도 조건이다. 이전 최종 평가 지도 32개와 격리 지도는 학습과 검증에서 제외했다. 기존 운영 프로필을 유지했다.
