# 차폐 기반 학습과 예방 재배치

이 실험은 수색기 전체가 중계망을 통해 연결되는지 평가한다. 0.5초 프레임 두 개 이상 끊긴 경우를 지속 단절로 기록한다.

## 예측 입력과 학습

3초 제어 경계에서 기존 PPO가 제안한 명령으로 실행 가능한 첫 구간을 구한다. 첫 구간 이후에는 현재 보정 유지와 명목 보정 복귀의 두 가정을 사용한다. 두 경로는 현재 위치와 첫 구간 종점을 공유한다.

입력은 각 가정의 수색망 연결 여유, 건물 손실 제거·현재 값 고정 시의 여유, 수색기 쌍별 여유, 취약 링크 비율, 최근 수신 전력·잡음·비컨 최신도다. 현재 계획기가 제공하는 이동 상태와 수신된 정보로만 계산한다. 지도·난수·실제 미래 채널은 모델 특징에 포함하지 않는다.

훈련 정답은 현재 연결 상태에서 새 단절이 3초 이상 7초 미만 뒤에 시작하는지와 0.5초 이상 3초 미만 뒤에 시작하는지다. 훈련 전용 지도에서만 모델을 맞추고, 별도의 보정·선정 지도에서 경보 문턱과 모델을 결정한다. 확인 비행의 모든 새 단절은 경보 재현율 분모에 남긴다.

## 예측값에서 중계 명령까지

```mermaid
flowchart LR
    A[공동 계획과 실제 수신 RF] --> B[두 경로의 반초별 수색망 여유]
    B --> C[학습한 선행 및 임박 위험 점수]
    C --> D[선행 위험이 높은 경우 중계 대안 비교]
    B --> D
    D --> E[두 경로와 초기 3초 안전 조건 확인]
    E --> F[중계기 한 대의 목표 보정]
```

기존 V18이 허용한 명령은 먼저 적용한다. 추가 개입을 고려할 때 선행 점수와 문턱, 임박 점수, 후보별 물리 여유와 우회 경로 여유를 함께 사용한다. 추가로 바꿀 명령은 기존 보정 배열의 중계기 한 행이다. 현 경로에서 얻은 학습 점수는 개입 시작을 판단하는 데 쓰며, 대안의 효과는 두 경로 가정의 물리 계산으로 비교한다.

예측 비교에서는 실제 PPO 명령을 고정한다. 별도의 폐루프 비교에서 V7, V18, V21의 명령이 각각 실제 이동에 적용된다. 결과에는 단절 시작률, 단절 시간, 기한 내 패킷 전달, 임무 완료, 안전, 중계 이동 거리를 포함한다.

기존 프로젝트의 가중치와 운영 프로필은 보존한다. 새 실행의 `artifacts/status.json`에서 단계와 완료 수를 확인할 수 있다. 원본 자료, 사용한 모델, 고정 문턱은 해시로 기록한다.
