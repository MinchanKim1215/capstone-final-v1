  운영 경보 기준에서 이전 혼합 모델이 그대로 선정됐다. 위0%p는 같은 모델을 기준선과 선정 후보로 표시한 결과다.

## 1. 실패 유형 진단

이전 고정 혼합 모델의 보정FA1 문턱0.77을 선택90비행에 적용했다. 전체 단절35,831개 중 위험 점수가 문턱에 이르지 않은 사건30,641개(85.52%), 경보 입력 자격이 없던 사건3,696개다.

최초 경보 재현율은3.99%, 높은 위험 점수가 사전에 한 번이라도 있었던 비율은4.04%다. 두 값의 차이가 작아, 기존 경보가 계속 켜져 있었다는 집계 문제만으로 낮은 탐지율을 설명하기 어렵다.

5초 이상 지속한 단절은23,577개다. 짧은 단절만 제외해서 해결된다고 판단하지 않았다. 최근 송수신이 관측된 링크는3,261개이며, 해당 범주의 최초 경보 재현율은9.63%다.

명령 변경·간섭 전환·전체 연결 하락과의 시간적 인접성은 events.csv에 기록했다. 이 연관성만으로 원인을 확정하지 않았다. 진단·수정에는 선택 자료만 사용했고, 이전 확인42비행을 새 학습 자료로 사용하지 않았다.


## 2. 패킷 서비스 정답 구성

기존 과제는 이론적 양방향 홉 성공확률 문턱 아래 상태가1초 이상 지속된 물리 링크 단절의 시작을 예측한다. 이 정의와 경보 분모를 유지했다.

새 과제는 수색 드론들이 생성한 패킷의 **250ms 내 전달률**이 최근1초 구간에서90% 미만인 상태가1초 이상 지속되는 시작을 예측한다. 각 시각에는 전달 마감시간이 이미 지난 패킷만 정답 계산에 포함했다. 마감시간250ms는 기존 시뮬레이터의 적시 전달 기준을 사용한 연구 가정이며, 실제 장비의 요구 규격이 아니다.

새 정답은 초기 구현부터250ms 경계에1e-10초(0.1나노초)의 수치 허용오차를 사용했다. 기존 엔진의 적시 전달 누계는 허용오차 없는 비교이므로 따로 검증했다. 경계에 걸린 패킷은83개/21,039,480개다. 확인 비행의 기록 검사에서 이 두 조건을 혼용한 오류가 발생해, 같은42비행을 보존하고 누락된 패킷 기록만 정확 재생으로 복원했다. 모델·정답 계산식·문턱은 바꾸지 않았다.

새 과제의 주 평가는 지정 중계드론1대(첫 중계드론)의 로컬 관측으로 수행했다. 다른 드론의 비공개 관측·미래 행동·미래 전파·정답 패킷 상태를 입력으로 주지 않았다. 이 출력은 향후 새로운 서비스 악화의 시작 위험이며 현재 서비스가 정상이라는 보증이 아니다.

기존335비행을 같은 명령으로 재생했다. 전체 이동·물리 링크 시각열, 제어 경계의 로컬 관측·수신 명령, 최종 패킷 전달·유실·지연 결과가 원본과 일치했다. 새 확인 비행은 원래 정책으로 비행을 마친 뒤 패킷 정답만 복사해 기록했다. 패킷 로그 추가가 비행이나 정책에 영향을 주지 않도록 분리했다.


## 3. 입력과 대조 학습

기존 링크 과제는 원래1,123,200표본·728개 특징을 그대로 사용했다. 서비스 과제는 기존 새훈련245비행과84개 관측오차 변형에서294,000개 표본을 만들었다. 같은 물리 비행의 원본/변형 표본 위치는 겹치지 않으며 두 변형의 표본 할당 합계는 같다.

서비스 기본 입력384개는 로컬 RF48항목·수신 명령9항목·선택적 에너지 측정·결측 여부의 현재/과거 요약과 공개 드론 수다. 추가48개 특징은 실제 수신한 수색 드론의 위치·속도·발행 명령·측정 나이와 공개 GIS로 계산한 현재·3초·7초의 직접 통신 가설이다. 미래 미발행 명령이나 실제 미래 위치는 사용하지 않았다.

## 4. 모델·문턱 고정과 새 확인

기존 선택 자료에서 모델을 고르고 별도 보정45비행에서 확률과 문턱을 정했다. 전체 목표를 만족하는 후보가 있으면 사건 재현율, 그렇지 않으면 정밀도90%·오경보1회/h 이하·경보50개 이상 운영점의 재현율, 해당 후보도 없으면 두 AP 평균으로 선택했다.

개발 전체 목표 예는 경보 정밀도90%·3초 이상 선행 최초 경보 재현율80%·오경보 및 늦은 경보1회/중계드론·시간 이하·경보50개 이상이다. 교수 지정값이나 실제 장비 인증 기준이 아니다.

모든 후보·두 난수 평균·문턱·평가 구현을 고정한 뒤 새 난수의 확인42비행을 생성했다. 같은14개 기존 지도에서 세 간섭 조건을 사용했으므로 새로운 지형 일반화 성능은 아니다. 기준선 예측기와 자료 생성 정책에는 과거 검증 노출 이력이 있으며, 원래 최종 지도32개는 열지 않았다.

기준선도 이번 새42비행에서 다시 평가했다. 따라서 이전 보고서의 다른 난수 비행에서 나온 기준선 수치와 달라질 수 있다. 비교는 같은 이번42비행 안에서 수행한다.

AP는 정밀도·재현율을 여러 문턱에 걸쳐 요약한 순위 지표다. 5초 AP는 현재 정상인 공통 관측에 한정하고3~7초 AP는 전체 공통 관측에서 계산했다. 실제 경보 정밀도·사건 재현율은 따로 확인한다.

| 간섭·잡음 전력 변화 | 31 | 34 |

마지막 열의 조건은 중복될 수 있다. 이는 표집한 사건의 시뮬레이터 내부 직전0.5초 분해이며, 전체 사건의 원인 분포나3초 전 예측 가능성의 상한이 아니다. 이 추가 진단으로 이미 고정한 모델·문턱을 변경하지 않았다.


## 7. 검증과 해석 한계

원시 물리 아카이브741개, 패킷 정답 아카이브377개와 정산 패킷21,039,480개를 검사했다. 기존 의존 파일187개와 이전 납품 산출물을 보존했다. 훈련 역할·공간 분리·원본/변형 표본 불중복·마감시간 정답 직접 계산·모든 후보 저장 예측의 재계산 일치를 확인했다.

실제 내보낸 두 API를 한 비행3,164프레임에서 검증했다. 링크 확률 최대 차이0, 서비스 확률 최대 차이0, 경보 판단 차이0개다. 필수 RF 결측은None을 반환하며 자동 경보는 비활성이다.

- 데스크톱link 추론: 첫643.83ms, 이후 중앙값6.41ms. 탑재 장치 지연 인증이 아니다.

- 데스크톱service 추론: 첫23.31ms, 이후 중앙값2.11ms. 탑재 장치 지연 인증이 아니다.

공간 그룹 재표집10,000회의 통계량은 유효 그룹별 AP 평균 차이다. 전체 관측 통합 AP 차이의 신뢰구간과 다르다. 양성 사건이 없는 비행의 AP는 정의 불가로 처리하며 오경보 집계에서는 제외하지 않았다.

환경은 기존2.4GHz·고도50m·이상적 TDMA·BPSK 성공확률·고정 간섭원 모델이다. 실제 Wi-Fi/IP 스택, 채널 경쟁·충돌, 실제 안테나/기체 자세, 실제 기체·통신모듈 측정 검증은 포함하지 않았다.

새 서비스 정답이 임무 의미에 가까워졌다는 사실은 기존 물리 링크 예측이 향상됐다는 증거가 아니다. 과제별 대조군 결과를 따라야 한다. 조건을 바꾸어 숫자가 커진 것을 기존 성능 향상으로 표시하지 않았다.

PPO는 자료 생성 정책으로 고정했다. 이번 결과를 새 재배치 정책의 연결 유지율·임무 시간 향상으로 해석하지 않는다. 미발행 미래 명령과 전조 없는 간섭은 현재 관측에 없는 정보이므로 정확한 발생 시각을 보장할 수 없다.
