# Final V1 · 관측 통신 여유 변화 검증

검증 완료 2026-11-05T14:16:29+09:00

실제 수신한 통신 여유의 최근 0.5초·1초·2초 감소량과 기울기 변화를 추가했을 때 3초 이상 선행 예측이 개선되는지 확인했다.

## 관측과 검증 방법

첫 중계기가 받은 비컨의 수신 SINR, 상대가 보고한 역방향 SINR, 성공한 데이터 전송의 ACK SINR을 사용했다. 마지막 수신 시각이 다른 두 측정만 차분했다. 같은 측정의 복사값, 마스크가 꺼진 값, 2초보다 오래된 값은 변화량으로 인정하지 않았다. 비컨은 1초 주기이고 ACK 관측은 성공한 전송이 있을 때 0.5초 구간에서도 갱신된다.

훈련 245개 지도, 154,312개 시점. 기존 특징 214개와 새 관측 특징 66개를 사용했다. 주요 모델의 학습 자료와 알고리즘 설정을 맞췄다. 현재 신호 수준·수신 여부·나이 12개만 추가한 대조 모델을 확인 비행 전에 별도로 등록했다. 보정 45비행에서 문턱을 정하고 별도 선정 45비행에서 갱신 횟수를 선택했다. 새 난수 42조건을 열기 전에 모두 고정했다. 확인은 알려진 지도 14개에서 수행했다.
