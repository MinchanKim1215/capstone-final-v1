## 실행

프로젝트 루트에서 다음과 같이 실행한다.

```powershell
& .\drone_forecast_joint_training\.venv\Scripts\python.exe -m final_v1_margin.campaign
```

245개 훈련 지도와 보정·선정 각 45비행은 기존 명령을 재생한다. 원본 위치·링크·패킷·비컨 수신 결과가 같은지 확인한다. 새 확인 비행 42개는 고정 V7 정책이 실제로 비행하며 모든 예측기는 그와 같은 궤적을 본다.

비컨 유입, 비컨 양방향 정보, 성공한 전송의 ACK 관측을 각각 사용한다. 새로운 두 측정의 시간차와 값 차이로 변화량을 계산한다. 새로운 측정이 없는 구간의 변화량은 결측으로 둔다. 측정 가능 비율과 수신 정보의 나이도 입력에 포함한다.

기존 특징만 사용하는 모델, 현재 관측값만 추가한 모델, 관측 변화만 사용하는 모델, 기존 특징에 변화량까지 추가한 모델을 비교한다. 현재값만 추가한 대조는 새 확인 비행을 열기 전에 별도 등록했다. 이를 통해 현재 신호 수준과 과거 변화량의 기여를 확인한다.

과거에 받은 값만으로 계산한 입력과 실제 미래 단절에서 만든 학습 정답을 분리한다. 실제 전체 통신망과 단절 유형은 평가·원인 분석에 사용한다.
